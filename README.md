# Sales Data Analysis Using Python

## Project Overview
A beginner-friendly Python project that analyzes sample product sales data using Pandas and Matplotlib.

## Technologies Used
- Python 3.12
- Pandas
- Matplotlib
- VS Code

## Features
- Calculate total sales revenue
- Calculate total units sold
- Identify highest and lowest revenue products
- Identify best-selling product by quantity
- Calculate average revenue and revenue percentages
- Generate bar charts and a pie chart
- Generate a text-based sales report

## How to Run
1. Install Python 3 and the required libraries: `py -3.12 -m pip install pandas matplotlib`
2. Run the project: `py -3.12 main.py`

## Dataset
The project uses a small sample CSV dataset containing five products, their quantities, and unit prices.

## Key Findings
- Total revenue: INR 377,000
- Total units sold: 33
- Highest revenue product: Laptop
- Best-selling product by quantity: Mouse
